# C / Python 語言離線程式設計編輯 / 執行環境(Offline Web-IDE)
 
### 開發者: 陳會安 + OpenCode 
### 官網: https://fchart.github.io/webide

一個**單一 HTML 檔案**的線上程式編輯與執行環境,雙擊或用 Chrome/ Safari 開啟即可使用,**完全離線、不需安裝、不需伺服器、不需系統管理員權限**,適合在 Windows / Android / iPhone / iPad 等各種平台上教學基礎 C 與 Python 程式設計。iPhone / iPad 可用本專案 `Offline-Web-IDE2\` 資料夾的 **PWA 版本**安裝成 App,詳見下方〈在 iPhone / iPad 安裝(PWA 版)〉。

## 功能特點

- **單一檔案、可攜式**:所有程式碼、編輯器、編譯/直譯引擎、程式碼片段與 AI 提示詞功能都內嵌在同一份 `.html` 檔案裡(約 2.5MB),複製到隨身碟、雲端硬碟或用 AirDrop / LINE 傳到平板都能直接開啟使用,不留任何安裝痕跡。
- **完全離線**:開啟後不需要任何網路連線,所有執行、片段插入、AI 提示詞產生、流程圖繪製都在瀏覽器本機完成,程式碼不會離開裝置。
- **跨平台**:同一份檔案可在 Windows / macOS 的 Chrome/ Safari,以及 Android、iPad 的瀏覽器上執行,不需要因平台不同而準備不同版本。
- **雙語言支援**:上方分頁可切換 **C** 與 **Python**,各自有獨立的編輯器與範例程式,切換分頁不會遺失內容。
- **語法高亮編輯器**:使用 CodeMirror,提供行號、C/Python 語法上色、自動縮排。
- **終端機介面**:用 xterm.js 呈現程式輸出,畫面風格接近真實主控台(與 VS Code 內建終端機同一套元件)。
- **C / Python 都支援真互動輸入**:Python 執行到 `input()`、C 執行到 `cin >>`、`scanf()`、`getchar()`、`gets()` 時,程式會真的暫停,等待使用者在終端機裡打字、按 Enter 才繼續往下執行。
- **程式碼片段選單**:內建「程式碼片段」下拉選單,C 有 **7 大類 52 個**片段、Python 有 **6 大類 50 個**片段,按一下即在游標處插入,自動處理縮排。
- **AI 助理選單**:內建 10 種 AI 提示詞模板(解釋程式碼、更多範例、語法測驗、除錯、修訂程式碼、分析演算法步驟、轉換為流程圖……),自動帶入目前編輯器的程式碼,產生提示詞並複製到剪貼簿;提示詞視窗內含 ChatGPT / Gemini / Copilot / Claude 按鈕,貼給雲端 LLM 就能得到教學輔助。
- **清除編輯器**:右上方 **🗑 清除** 按鈕可一次清空目前編輯器的全部程式碼(會先確認,避免誤刪)。
- **流程圖工具**:內嵌 flowchart.js,可把 vision 演算法畫成 SVG 流程圖,支援即時預覽、剪貼簿貼上與 SVG 下載。
- **中文訊息正確顯示**:C 程式用 `printf` 印出的中文提示文字(可與 `%d` 等格式化符號混用)能正確顯示,細節見下方〈已知限制〉。
- **開啟 / 儲存檔案**:可以匯入既有的 `.c` / `.py` 原始碼檔案繼續編輯,也可以把目前編輯器內容另存成檔案下載。
- **執行快捷鍵**:除了按 **▶ 執行** 鈕外,也可按 `Ctrl+Enter`(Mac 為 `Cmd+Enter`)直接執行;把滑鼠移到執行鈕上時會以 tooltip 提示此快捷鍵。
- **中斷執行(停止卡住的程式)**:▶ 執行鈕右側有下拉箭頭「▾」,點擊可選擇「⏹ 中斷執行」。遇到無窮迴圈、等待輸入卡住或執行太久的程式時,點中斷會重新整理頁面,立即停止執行;編輯器內容與終端機紀錄會自動還原(靠 localStorage 自動儲存)。
- **執行逾時保護**:C 程式的 CPU 運算時間上限 15 秒(等待使用者輸入與分頁被切到背景的時間都不計入)、Python 程式 15 秒(每次執行重新起算,執行中切到別的 App 再回來會重新計時),避免初學者不小心寫出的無窮迴圈把瀏覽器分頁卡死。
- **深色 / 淡色佈景切換**:右上角 **☀️ 淡色 / 🌙 深色** 按鈕可一鍵切換整體佈景(編輯器、終端機、選單一起換)。上課投影時建議切到**淡色**,學生比較看得清楚;設定會記在瀏覽器,下次開啟自動套用。
- **自動儲存編輯內容**:程式碼每次修改後即自動存入瀏覽器的 localStorage(不必手動按儲存)。跳去 ChatGPT / Gemini 等 AI 網頁、或 iOS 把 PWA 佔用的記憶體回收而重載頁面時,再回到環境會自動還原 C 與 Python 兩個編輯器的內容與上次使用的語言分頁,程式碼不會消失。
- **觸控優化**:選單項目加大 Padding、行高與觸控目標,選單捲動支援 iOS 慣性滑動,平板上用手指操作不易誤觸;iPad / Android 平板載入時**不會自動彈出虛擬鍵盤**(點一下編輯器才彈),並支援圓角螢幕 / Split View / 全螢幕的安全區(safe-area)留白,頂部工具列與底部狀態列不會被系統手勢區遮住。

## 使用的編譯 / 直譯引擎

這個環境刻意選用「純 JavaScript 實作」的引擎,而不是 WebAssembly(WASM)版本的編譯器。原因是 WASM 型的編譯器(例如 Clang/LLVM 編譯成 WASM)體積動輒數十 MB,而且在 iPad 上會受 iOS Safari 對 WebAssembly 記憶體配置的嚴格限制,實務上容易在較舊或較低階的平板上直接當機。純 JS 引擎完全不使用 WebAssembly.Memory,可以避開這個風險,檔案也小得多。

| 語言 | 引擎 | 說明 |
|---|---|---|
| C | **JSCPP** | 純 JavaScript 實作的 C 直譯器,支援 `stdio.h`(`printf`/`scanf`)、變數、條件、迴圈、陣列、函式、指標等基礎語法。 |
| Python | **Skulpt** | 純 JavaScript 實作的 Python 直譯器,支援 `input()` 真互動輸入、常見的基礎語法與部分標準函式庫。 |
| 編輯器 | **CodeMirror 5** | 提供語法高亮與行編輯功能。 |
| 終端機 | **xterm.js** | 提供類終端機的輸出入介面。 |
| 流程圖 | **flowchart.js + Raphael** | 將流程圖文字繪製成 SVG。 |

> 這兩顆引擎都是「直譯」而非「真編譯」,不會產生實際的機器碼或執行檔,速度也比原生編譯器慢,但對教學用的基礎練習(幾十~幾百行)完全足夠。

### 關於 C++ 與 Arduino

本環境的片段選單刻意**只提供純 C 語法**(`stdio.h`、`printf`/`scanf` 等),不含 C++(`cout`/`cin`、`iostream`)與 Arduino 片段。原因是 JSCPP 對 C++ 的物件導向支援並不完整,為了避免學生在離線環境寫出無法執行的 C++ 程式,選單已將 C++ 與 Arduino 選項移除。若需要練習 C++,仍建議使用完整版的 VS Code 延伸套件。

## 使用說明

### 開啟環境

直接用 Chrome/ Safari(或其他現代瀏覽器)開啟這份 `.html` 檔案即可,不需要安裝任何軟體、不需要連網路。

> 這份 `.html` 是「單檔」版本,適用於 Windows / Android / iPad 直接開啟。iPhone 無法直接由檔案開啟本機 `.html`,請改用下方的 PWA 版本。

### 安裝為 App(PWA 版)

iOS 的 Safari 不像 Android 可以直接開啟檔案管理員裡的本機 `.html` 檔,而且 PWA 的離線快取(Service Worker)必須由 HTTPS 網域提供。因此本專案另外提供 `Offline-Web-IDE2\` 資料夾的 **PWA(漸進式網頁應用程式)版本**:可把整個環境「安裝」成 App,像原生 App 一樣**全螢幕執行、無網址列、離線使用**(iPhone / iPad / Android 都適用)。

PWA 資料夾內容:

| 檔案 | 作用 |
|---|---|
| `index.html` | 主程式(與根目錄的 `.html` 同內容,另加入 manifest 連結與 Service Worker 註冊) |
| `manifest.json` | App 名稱、圖示、全螢幕顯示設定 |
| `sw.js` | Service Worker,安裝時預先快取全部資源、離線時從快取提供 |
| `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` | App 圖示 |

#### 為什麼需要 HTTPS?

Service Worker(離線快取)**只有在 HTTPS(或 localhost)下才能運作**。直接用手機開啟本機 `file://` 檔案,或從區網 `http://192.168.x.x` 開啟,都無法註冊 SW、不會有離線快取——這種情況「加到主畫面」只是書籤捷徑,沒連網就打不開。免費的 **Netlify** 與 **GitHub Pages** 都會自動提供 HTTPS,擇一使用即可(下方兩種步驟任選一種)。

#### 第一步:上傳到 Netlify(每台裝置只需做一次)

1. 準備好 `Offline-Web-IDE2\` 資料夾裡的全部檔案:`index.html`、`manifest.json`、`sw.js`、`icon-192.png`、`icon-512.png`、`apple-touch-icon.png`。
2. 開啟 https://app.netlify.com/drop(不需註冊即可上傳,建議登入以便日後更新)。
3. 把**資料夾「裡面的」這些檔案**(不是資料夾本身)直接拖曳進網頁視窗。
4. 部署完成後 Netlify 會給一組網址(例如 `https://your-app-name.netlify.app`),記下來並用瀏覽器開啟確認環境正常。
5. 確認網址列的網址是 `https://` 開頭。

> **之後要更新內容時**:把新的 `index.html`(與 `sw.js`)再次拖進同一網址的 drop 頁面重新部署即可。若 `sw.js` 的 `CACHE_NAME` 版本號有變更(目前為 `web-ide-v11`),舊快取會自動清除並重新下載,重新載入頁面一次即生效。

#### 或者:部署到 GitHub Pages(替代方案)

1. 在 GitHub 建立一個**公開**儲存庫(名稱取短一點,網址會是 `<帳號>.github.io/<儲存庫名>`,比較好記)。
2. 把上述 6 個檔案上傳到儲存庫**根目錄**(網頁介面按 **Add file → Upload files**,或用 git push)。
3. 儲存庫 **Settings → Pages** → Source 選 `Deploy from a branch`,Branch 選 `main` / `(root)`,按 **Save**。
4. 等 1~2 分鐘,開啟 `https://<帳號>.github.io/<儲存庫名>/`,確認網址列是 `https://` 開頭。
5. 之後更新:重新上傳檔案即可;`sw.js` 版本號遞增規則與 Netlify 相同。

> 本專案所有路徑皆為相對路徑(`./sw.js`、`./index.html`、manifest 的 `start_url: "./index.html"`),放在 GitHub Pages 的子路徑(`<帳號>.github.io/<儲存庫名>/`)下也能正常註冊 Service Worker,不需改任何程式碼。iOS / Android 安裝步驟同下方,把網址換成 GitHub Pages 網址即可。

#### 第二步:iOS(iPhone / iPad)安裝

1. 用 **Safari** 開啟剛才的部署網址(Netlify 或 GitHub Pages)。
2. 第一次開啟後,程式會自動下載並快取離線資源(畫面上不會有提示,屬正常)。
3. 點 Safari 工具列的 **分享** 按鈕(方塊+上箭頭圖示)。
4. 在選單中點 **加到主畫面**。
5. 名稱確認後按 **新增**,主畫面即出現 Web-IDE 圖示。
6. 之後直接從主畫面圖示啟動,即為全螢幕、可離線使用的 Web-IDE。

#### Android 安裝

1. 用 **Chrome** 開啟剛才的部署網址(Netlify 或 GitHub Pages)。
2. 點右上角 **⋮ 選單** → **安裝應用程式**(部分版本顯示「加到主畫面」)。
3. 按 **安裝** 即可,主畫面會出現 App 圖示,之後可全螢幕、離線啟動。
4. (也可直接沿用根目錄的單檔 `.html` 版本,不需安裝。)

#### 驗證是否真的可離線使用

1. 首次開啟並安裝後,**先關閉 Wi-Fi / 行動網路**(或開飛航模式)。
2. 從主畫面點 Web-IDE 圖示。
3. 能正常開啟並執行程式,代表離線快取成功。
4. 進階確認:電腦 Chrome/ Safari 開啟同一網址 → 按 F12 → **Application** 分頁 → **Service Workers**,狀態應為 **activated**(綠色、可執行);若出現 SecurityError,表示網址不是 HTTPS。

#### 常見問題

| 問題 | 原因 / 解法 |
|---|---|
| 主畫面圖示點下去打不開 | 這是舊的「書籤捷徑」,沒有 SW 快取(之前用 `file://` 或 http 區網安裝的)。請改用 **HTTPS 網址重新安裝一次**,先連網開啟過、再做離線測試。 |
| 沒有「安裝應用程式」選項 | 確認網址是 HTTPS、`index.html` 與 `sw.js` 在網站根目錄同一層、網頁能正常載入;SW 註冊失敗時 Chrome/ Safari 不會提供安裝。 |
| 更新上傳後還是舊版本 | 瀏覽器會沿用舊快取。上傳新版時把 `sw.js` 的 `CACHE_NAME` 版本號上升(如 `web-ide-v7` → `web-ide-v8`),重新載入頁面讓新 SW 生效(註冊腳本已設定 `updateViaCache: 'none'` + 新 SW 生效時自動重載一次)。 |
| iOS 太舊(低於 16.4) | Service Worker 離線快取支援不完整,「加到主畫面」只會是書籤;請升級 iOS,或維持「先連網開啟」的用法。 |

### 切換語言

點選畫面左上角的 **C** 或 **Python** 分頁即可切換,兩個語言各自保留獨立的編輯器內容與範例程式。

### 撰寫與執行程式

1. 在左側編輯器輸入程式碼(每個語言各自保留獨立的程式內容,切換分頁不會遺失)。
2. 點選右上角 **▶ 執行**,或按快捷鍵 `Ctrl+Enter` / `Cmtrl+Enter` / `Cmd+Enter`。若程式卡住(無窮迴圈、等待輸入等),可點執行鈕右側的 **▾** 箭頭,選擇 **⏹ 中斷執行** 重新整理頁面立即停止(編輯器與終端機內容會自動還原)。
3. 執行結果會顯示在右側「執行結果 / 終端機」區塊。
   - 輸出行數超過終端機高度時,內容會在**終端機框內**出現捲動軸並於框內捲動,最後一行不會溢到下方的狀態列。

### 插入程式碼片段

1. 點選上方 **程式碼片段 ▾** 按鈕。
2. 在展開的分類(如「基本程式結構」「動作符號」)下方點選想要的片段名稱。
3. 片段會以「選單中的名稱」顯示於選單,點擊後在目前游標位置插入對應程式碼,並自動帶入縮排。

>> C 片段涵蓋:基本程式結構、動作符號、輸入和輸出符號、決策符號、函數、陣列、指標。
>> Python 片段涵蓋:動作符號、輸入和輸出符號、決策符號、程序和函數、串列 (List)、字典 (Dict)。

### AI 輔助學習(離線產生提示詞)

1. 點選上方 **AI 輔助學習 ▾** 按鈕。
2. 選單分為 **看懂程式碼**、**除錯程式碼**、**了解程式結構** 三個區塊,區塊標題為固定文字,項目直接展開顯示。
3. 選擇想要的輔助方式,例如:「📖 解釋程式碼」「🧩 更多範例」「❓ 語法測驗」「🐞 除錯錯誤訊息」「📝 分析演算法步驟」「🔄 轉換為流程圖」……。
4. 系統會**自動抓取目前編輯器裡的程式碼**(若有選取範圍則使用選取範圍),套用到模板中,產生一段結構完整的 AI 提示詞。
5. 提示詞會自動複製到剪貼簿,並在彈出的視窗中顯示;視窗底部的 **ChatGPT / Gemini / Copilot / Claude** 按鈕會在新分頁開啟該 AI 網站,直接貼上提示詞即可。
6. 提示詞中也包含「以繁體中文回答」等要求,因此即使連上國外 AI 服務,回答仍會是繁體中文。
7. 使用「🐞 除錯錯誤訊息」時,自動帶入提示詞的終端機輸出會先**逐行去除頭尾空白、移除空白行**,避免錯誤訊息殘留多餘空白或產生多行空行。

> 這套系統本身不做任何 AI 運算、不需 API Key、不把程式碼傳給任何伺服器;它只負責「整理出一段好用的提示詞」,是否連上外面的 AI 服務完全由學生自己決定。

### 流程圖工具

- 從 **AI 助理 ▾ →「📊 開啟流程圖工具」** 開啟,把 flowchart.js文字(如 `st=>start: 開始`)貼進去即時畫成 SVG 流程圖。
- 也可將剪貼簿內容貼上(`📋 貼上剪貼簿`)、載入範例(`📄 使用範例`)、或將流程圖下載成 `.svg`(`⬇ 下載 SVG`)。
- 從 **「🔄 轉換為流程圖」** 會自動把目前編輯器的程式碼轉成 flowchart.js 文字並開啟工具。

### 關於程式的輸入(scanf / cin / input)

- **Python**:直接在終端機裡打字即可。程式執行到 `input()` 會自動停下來等你輸入,按 Enter 送出後繼續執行。
- **C**:與 Python 相同的互動方式。程式執行到 `cin >>`、`scanf()`、`getchar()` 或 `gets()` 時會自動暫停,游標停在終端機等你輸入;打字後按 Enter,程式就繼續往下執行。需要多個值時,可以一次在同一行以空白隔開(如 `3 4`),也可以分行多次輸入,完全依照程式讀取的順序即時供應,**不需要事先填寫任何輸入欄位**。

### 開啟既有檔案

點選 **📂 開啟**,選擇裝置上的 `.c` / `.py` 檔案,內容會自動載入到對應語言的編輯器,並自動切換分頁。

### 儲存 / 匯出檔案

點選 **💾 儲存**,會把目前分頁編輯器裡的內容,依照上方檔名欄位(可自行修改)下載成檔案。

- **Android**:通常直接存入「下載」資料夾。
- **iPad(Safari)**:會跳出分享/儲存選單,選「儲存到檔案」即可存到 Files app,之後可以用〈開啟既有檔案〉的方式再次載入編輯。

### 清除畫面與清除程式碼

- **清除畫面**:點選終端機工具列的 **清除畫面**,可以清空目前的執行結果顯示,不會影響已寫的程式碼。
- **清除程式碼**:想刪掉目前編輯器裡的整份程式碼時,點選右上方 **🗑 清除**,系統會先問「確定要清空目前編輯器的全部程式碼嗎?」,按確定後整個編輯器內容清空,游標回到編輯器。

### 切換深色 / 淡色佈景

點選右上角 **☀️ 淡色 / 🌙 深色** 按鈕即可切換佈景:

- **深色**(預設):適合個人使用,長時間看螢幕較不刺眼。
- **淡色**:適合**上課投影**或光線充足的教室,白底深字對比清楚,學生看得比較清楚。
- 切換會同時套用到編輯器、終端機、選單與視窗;設定記在瀏覽器的 localStorage,下次開啟自動沿用。

### 自動儲存與還原編輯內容

程式碼是**自動儲存**的,不需要手動操作:

- 在 C 或 Python 編輯器打字後約 0.3 秒,內容即自動存入瀏覽器的 localStorage(含最後使用的語言分頁)。
- 跳去 ChatGPT / Gemini / Copilot / Claude 等 AI 網頁再切回來、或系統把分頁 / PWA 重載(例如 iOS 回收記憶體),編輯器會自動還原**兩個語言的程式碼**與上次的分頁,不會遺失。
- 注意:此機制依賴瀏覽器的 localStorage。若以「無痕 / 隱私視窗」開啟、或清除了瀏覽器的網站資料,自動儲存的內容會一併被清除;重要程式碼仍建議偶爾用 **💾 儲存** 下載備份。
- **🗑 清除** 清空編輯器後,「空的狀態」也會被記住(重開頁面仍是空的);此時可用 **📂 開啟** 載入之前存下的檔案。

## 已知限制

這是刻意精簡、聚焦在「基礎程式語法教學」的版本,以下情況目前**不支援**,使用教材時請避開:

1. **視窗 / GUI 程式設計**:不支援 Python 的 `tkinter` 或任何圖形介面函式庫,因為瀏覽器沙盒裡沒有原生視窗系統可以呼叫。適合主控台輸出入(`print`/`input`、`printf`/`scanf`)類型的基礎練習。
2. **C++ / OOP / Arduino**:選單不提供(如上所述),JSCPP 對 C++ 物件導向支援不完整。
3. **中文文字的處理範圍(僅限 C)**:
   - ✅ 可以:C 程式用 `printf` **輸出**中文提示或訊息文字(可與 `%d`、變數等混用),包括先存進 `char` 陣列再印出來。
   - ❌ 不行:使用者**輸入**中文字串(例如 `scanf("%s", name)` 讓使用者打中文名字)。
   - ❌ 不行:把**單一**中文字元存進 `char` 變數(例如 `char c = '你';`),會出現溢位錯誤——這是 JSCPP 引擎本身的限制(`char` 型別完全無法儲存任何非 ASCII 字元,連原始 UTF-8 位元組都不行),執行結果的終端機會顯示提示訊息說明這是已知限制。
   - Python(Skulpt)沒有這個限制,中文字串的輸入、輸出、變數處理都能正常運作。
4. **套件 / 函式庫**:C 僅支援 JSCPP 內建的基礎函式庫(`stdio.h` 等常用標頭),Python 僅支援 Skulpt 內建的部分標準函式庫,無法 `pip install` 或使用未內建的第三方套件。Turtle 海龜繪圖也不支援(單頁環境無繪圖視窗)。
5. **執行速度**:兩者都是直譯執行,速度比真正編譯器慢,不適合運算量大的練習(例如大範圍迴圈跑數學運算),教學用的短小範例完全沒問題。
6. **檔案管理**:採「匯入 / 匯出」模式,不是像桌面 IDE 那樣「開啟後可直接存回原檔」,每次儲存都是「另存新檔」下載一份新檔案。
7. **同一頁面連續執行**:部分環境在同一個頁面連續按兩次執行時,第二次可能不會重新輸出(第一次執行成功後引擎狀態問題);遇到時可重新整理頁面再執行。詳細追蹤見 DEV_Note.md。
8. **C 的 `scanf` 不能直接讀入陣列元素(`&arr[i]`)**:JSCPP 引擎的 `scanf` 只認得純量變數(如 `int x`)的位址,對「陣列元素位址」寫入未支援——`scanf("%d", &arr[i]);`(含 `scanf("%d", arr + i)` 等任何落點在陣列的位址)會出現 `Memory overflow` 錯誤。同一段程式在真實編譯器(gcc / Visual Studio)完全合法,屬引擎限制。**替代寫法**:先讀入暫存變數再賦值:
   ```c
   int tmp;
   for (i = 0; i < SIZE; i++) {
       scanf("%d", &tmp);
       arr[i] = tmp;   /* 先讀進 tmp,再放入陣列 */
   }
   ```
   對陣列的一般賦值(`arr[i] = 7`)與透過指標解參考寫入(`*p = 9`)都不受影響,只有經由 `scanf` 直接寫入陣列元素才會觸發(細節見 DEV_Note.md §6.5)。
9. **C 的 `struct`(結構)不支援**:JSCPP 引擎未實作 struct 型別——連最基本的定義都會直接拋出 `type struct Student is not defined`;`typedef struct`、結構指標與 `->` 存取同樣失敗(2026-08-22 實測)。片段選單的「結構」分類已整組移除以免誤導學生;需要聚合資料時,教學上可先以**多個獨立變數**或**平行陣列**(如 `int id[50]; float score[50];` 以相同索引對應同一筆)替代(細節見 DEV_Note.md §6.6)。
